## المشكلة القائمة

**٥ مشاريع Vercel** موصولة بهذا الريبو (فريق `almond-k`)، **كلها تفشل** على كل دفعة:

| المشروع | ملاحظة |
|---|---|
| `almond` | الاسم النظيف — **المرشّح للإبقاء** |
| `almond-ph3q` | لاحقة عشوائية من Vercel = محاولة استيراد مكرّرة |
| `almond-ksn5` | نفس الشيء |
| `almond-almond-web` | نفس الشيء |
| `almond-almond-web-6ok1` | نفس الشيء |

اللواحق العشوائية (`ph3q`/`ksn5`/`6ok1`) يضيفها Vercel تلقائياً حين يكون الاسم مأخوذاً — أي أنّ كلّ محاولة «Import Project» أنشأت مشروعاً جديداً بدل إصلاح القائم.

### الأدلّة (كلها متحقَّقة)
- **الفشل قديم على `main` نفسه، لا يخصّ فرعاً بعينه:** نفس الخمسة فشلت على PR #80 (٤ آب، وهو رأس `main`) وعلى PR #81 (١٦ آب).
- **الكود سليم:** `npm install && npm run build --workspace almond-web` **ينجح** من جذر الريبو محليّاً ⇒ الخلل في **إعداد Vercel** لا في الشيفرة.
- **لا موقع حيّ يمكن أن ينكسر:** `almond.jo` و`www.almond.jo` **بلا سجلّ DNS** إطلاقاً.
- **`almondjo.com` غير معنيّ:** هو «ALMOND — نظام إدارة الفروع» من ريبو **`production-almond`** (مشروع Vercel اسمه `almondjo`) — منفصل تماماً، لا تمسّه هذه الفوضى.

> تحلُّل `*.vercel.app` في DNS **لا يثبت وجود مشروع** — Vercel يحلّ أيّ اسم تحت النطاق.

## الإجراء (لوحة Vercel — يدويّ)

لكلّ مشروع من الأربعة الزائدة، بهذا الترتيب:

1. **Domains** → تأكّد أنّه **فارغ** (لا نطاق مخصّص). هذا الفحص **إلزاميّ** قبل أيّ خطوة.
2. **Settings → Git → Disconnect** — **افصل، لا تحذف.** الفصل **عكوس بالكامل** ويوقف فوراً البناءات الفاشلة الخمسة على كلّ دفعة (وهي تحرق دقائق البناء).
3. بعد أسبوع من الاستقرار، احذفها إن شئت.

**أبقِ `almond` وحده**، ثمّ اضبط مساراً واحداً لا غير:

- **(أ) Root Directory = جذر الريبو** ← يستعمل `vercel.json` الجذر الحاليّ (`buildCommand: npm run build --workspace almond-web`). **الأبسط**، ومُتحقَّق أنّه يبني محليّاً.
- **(ب) Root Directory = `almond-web`** ← فعّل **Include files outside the Root Directory** (لأجل حزمة `@almond/shared`)، و**احذف `vercel.json` الجذر** (يُتجاهَل في هذا الوضع فيسبّب لبساً فقط).

⚠️ **لا تخلط بينهما.** الخلط هو أرجح تفسير للفشل الحاليّ: مشروعٌ جذرُه `almond-web` بينما أمر البناء `--workspace` لا يعمل إلّا من جذر الريبو.

## ✅ القرار المثبَّت — الخيار (أ)

> ثُبِّت **2026-09-08**. هذا هو ما يطلبه القسم التالي، وهو ما يُنهي التذبذب.

**Root Directory = جذر الريبو**، ويُستعمل `vercel.json` الجذر كما هو الآن:

```json
{
  "framework": "nextjs",
  "installCommand": "npm install",
  "buildCommand": "npm run build --workspace almond-web"
}
```

**لماذا (أ):** هي ما يُجسّده الملف فعلاً اليوم، وهي «الأبسط» بنصّ هذا المستند،
ومُتحقَّق أنّ `npm run build --workspace almond-web` ينجح من الجذر ويولّد ٣٥ صفحة.

🔴 **`outputDirectory` ممنوع في الخيار (أ).** باني Next.js في المونوريبو يحلّه
**نسبةً إلى مجلّد التطبيق المكتشَف** لا إلى الجذر، فتصير القيمة
`almond-web/almond-web/.next` ويفشل التقاط المخرجات بعد نجاح البناء. هذا ما
سجّله `80314e3`، وهذا ما أُعيد خرقه في الدورة الخامسة أدناه.

**قبل أيّ تعديل قادم على `vercel.json`: عُد إلى هنا أوّلاً.**
