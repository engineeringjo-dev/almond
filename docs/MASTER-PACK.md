# الجزء الأول: التصميم وأسلوب ستاربكس

## 1. نظام الألوان (theme واحد قابل للتبديل)

اجعل كل الألوان في `constants/theme.ts`، قابلة للتبديل من مكان واحد:

```typescript
export const greenTheme = {   // تجريبي للمقارنة
  primary:    '#00704A',
  primaryDark:'#1E3932',
  accent:     '#D4A24E',
  neutralWarm:'#D4E9E2',
  cream:      '#F7F4EF',
  cardBg:     '#FFFFFF',
  textPrimary:'#1E3932',
  textSecondary:'#6B7B74',
  success:    '#00704A',
  error:      '#C0392B',
};

export const almondTheme = {  // الهوية الرسمية للنشر
  primary:    '#1A0F08',
  primaryDark:'#1A0F08',
  accent:     '#D4A24E',
  neutralWarm:'#EFE6D6',
  cream:      '#F7F1E6',
  cardBg:     '#FFFFFF',
  textPrimary:'#1A0F08',
  textSecondary:'#8A7A66',
  success:    '#2D6A4F',
  error:      '#C0392B',
};

export const theme = greenTheme; // ← بدّل إلى almondTheme للنشر الفعلي
```
**ملاحظة:** الأخضر تجريبي للمقارنة فقط. للنشر، بدّل إلى almondTheme (هوية ألموند البني+الذهبي).

## 2. التوزيع بأسلوب ستاربكس (كل الشاشات)

### الرئيسية (ترتيب ستاربكس):
1. شريط علوي نظيف: تحية + فرع + إشعارات.
2. **بطاقة المكافآت ضخمة (Hero)** فوق مباشرة: نقاط كبيرة + تقدّم مرئي + الكوب.
3. زر "اطلب الآن" بارز.
4. رصيد المحفظة + شحن سريع.
5. "طلبك المعتاد" (إعادة طلب بضغطة).
6. أقسام أفقية تنزلق (عروض/منتجات) بصور كبيرة.
7. مساحات واسعة مريحة (سرّ أناقة ستاربكس).

### المنيو:
- صور منتجات كبيرة (placeholder احترافي موحّد الآن + بنية imageUrl للصور الحقيقية لاحقاً).
- تصنيف أفقي (chips) + بطاقات بصور بارزة + مساحات مريحة.
- **لا emoji عشوائي إطلاقاً** — أيقونات/صور موحّدة.

### كل الشاشات: نفس اللغة — مساحات واسعة، بطاقات نظيفة، تباين قوي، أساسي للعناصر الرئيسية + ذهبي للتمييز.

## 3. عناصر بصرية
- بطاقة الولاء = عنصر بطل كبير ملوّن.
- الكوب = أنيميشن امتلاء جميل.
- أقسام أفقية بصور كبيرة.
- التقدّم المرئي دائماً ("كم باقي").
- Empty states ودّية (رسم + نص + CTA).

# الجزء الثاني: عوامل نجاح ستاربكس (طبّقها)

1. تدفّق واحد سلس: تصفّح → تخصيص → دفع → نقاط، بأقل ضغطات.
2. الطلب المسبق + استلام سريع (بارز).
3. المحفظة المشحونة + شحن بضغطة.
4. تخصيص غني لكل مشروب (حليب/سكر/ثلج/إضافات/حجم).
5. Personalization: طلبك المعتاد + اقتراحات.
6. المكافآت كعادة (مرئية في كل مكان مناسب).

# الجزء الثالث: إزالة عوامل فشل ستاربكس (إصلاحات إلزامية)

1. **Redeem واضح:** "ادفع بالنقاط" عند الدفع مع رصيد + كم نقطة = كم دينار + كم ستوفّر.
2. **توفّر الأصناف:** عرض حالة كل صنف؛ غير المتوفّر "غير متوفّر حالياً" ولا يُضاف.
3. **تعديل الطلب:** مهلة 30 ثانية للإلغاء/التعديل بعد التأكيد (عدّاد تنازلي).
4. **دقة وقت الجاهزية:** Smart Pickup بوقت واقعي + تتبّع واضح.
5. **مرونة الدفع:** كل الطرق + النقاط تُكتسب على الجميع (ليس المحفظة فقط).
6. **تنقّل متّسق:** شريط سفلي ثابت، نفس المنطق كل الشاشات.
7. **دخول بسيط:** هاتف + OTP بأقل خطوات + وضع ضيف.

# الجزء الرابع: تفاصيل ألموند المحسومة (لا تُغيّر — طبّقها كلها)

## A. نظام الولاء — الشرائح
**النموذج: آخر 12 شهر متحرّكة (Rolling 12-Month).** الشريحة = مجموع الإنفاق في آخر 365 يوم من اليوم (نافذة متحرّكة، تتحدّث يومياً؛ قد تنزل الشريحة لو خفّ الإنفاق).

| الشريحة | إنفاق آخر 12 شهر | المضاعف |
|---------|------------------|---------|
| Bean / بين | 0 د.أ | ×1.0 |
| Silver / فضي | 100 د.أ | ×1.25 |
| Gold / ذهبي | 300 د.أ | ×1.5 |
| Black / أسود | 750 د.أ | ×2.0 |

طبّق في `loyaltyService.mock.ts` ومنطق الخادم.

## B. شاشة الولاء
- اعرض **السلّم كامل** (الأربع شرائح) بشريط تقدّم متعدّد المحطات.
- لكل شريحة، المتبقي بوضوح: "أنفق X د.أ خلال آخر 12 شهر للوصول إلى Y".
- نص صغير: "بناءً على إنفاقك في آخر 12 شهراً".

## C. الكوب (Filling Cup)
- يُملأ بصرياً بحبات/سائل ذهبي متدرّج + أنيميشن spring.
- الهدف 10 كاسات، نقطة سبق = يبدأ على 1.
- الدفع من الرصيد = 1.5 حبة كوب.
- عند الاكتمال: احتفال + قسيمة مشروب مجاني + إعادة للكوب على 1.

## D. عجلة الحظ
- نص بارز: **"اربح مجاناً 🎁"** على البطاقة وداخل الشاشة.
- دورة كل 5 زيارات، أو شحن Gift Card بـ50 د.أ.
- 10 جوائز بأوزان (controlled من Admin Panel — §13 في SPEC). اختيار الجائزة دائماً على الخادم (anti-cheat).
- الجوائز غير النقدية تنتهي خلال 7 أيام.

## E. الإحالة (ادعُ أصحابك)
- بجانب "ادعُ أصحابك": نص **"واربح 50 نقطة"**.
- شاشة الإحالة: العرض بارز في الأعلى "ادعُ أصحابك واحصل على 50 نقطة".
- المُحيل يربح 50 نقطة **مرة واحدة بالمطلق** عند تسجيل أول صديق (OTP-verified). حماية: OTP فريد، منع الإحالة الذاتية.

## F. تقييم الفرع
- 50 نقطة **مرة واحدة بالمطلق** لأول تقييم. التقييمات اللاحقة تُقبل بدون نقاط.
- prompt بعد إتمام الطلب: "كيف كانت تجربتك في فرع X؟" نجوم 1–5.

## G. الجمعة
- النص الظاهر: **"+50% نقاط كل جمعة ☕"** (المنطق ×1.5 خلفياً).

## H. الفروع (10 فروع — القائمة الكاملة الصحيحة، استبدل أي قائمة حالية)

## I. تدفّق الطلب — اختيار النوع أولاً
عند "اطلب الآن": يختار النوع أولاً:
- 🏃 **استلام (Pickup)** → داخل التطبيق (فرع + وقت جاهزية ذكي).
- 🛵 **توصيل** → تحويل خارجي إلى `almondcoffeehouse.com/order` (الأغريغيتر).

## J. زر "أقرب فرع لي" (الرئيسية)
- زر بارز → GPS → أقرب فرع + المسافة → 3 خيارات: استلام / توصيل / الموقع على Google Maps.
- كل فرع في القائمة له زر Google Maps خاص.

## K. المحفظة
- رصيد بارز في الرئيسية + بانر "اشحن محفظتك" مع: "ادفع من رصيدك واملأ كوبك 1.5× أسرع".

## L. الاستبدال (Redeem)
- "ادفع بالنقاط" عند الدفع (100 نقطة = 1 د.أ). واضح جداً.

## M. الدفع (طرق)
كاش، CliQ، Visa، Mastercard، PayPal، محفظة. النقاط تُكتسب على كل الطرق.

## N. الدخول
هاتف (+962) + OTP، 6 أرقام، resend 60 ثانية، وضع ضيف.

## O. نقاط + أسعار
- 5 نقاط لكل 1 د.أ. الأسعار بصيغة X.XXX د.أ. (Price2 مرجع الأسعار).
- عرض البرانش: BR + مشروب = خصم 1.000 د.أ تلقائي.

## P. مصدر البيانات
- Odoo مصدر المنيو/الأسعار/الطلبات (mock نشط الآن، يتبدّل بمتغيّر `DATA_SOURCE`).
- خادم الولاء منفصل. الأغريغيترز: بنية جاهزة، غير مفعّلة.
- لوحة التحكم (admin-panel): تحكم العجلة + الحملات + Geofence + مكافأة الزيارة.
