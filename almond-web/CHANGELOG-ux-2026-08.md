## التفاصيل حسب المجال

### ١) الضريبة ٨٪ (مصدر واحد)
- `packages/shared/src/config/index.ts`: `TAX_RATE` صار `0.08`.
- الويب: `CartSummary` يعرض `t('tax', { rate: Math.round(TAX_RATE*100) })` — لا رقم مكتوب يدويًّا.
- التطبيق: `almond-app/components/cart/Summary.tsx` + `locales/{ar,en}.json` — اللابل «الضريبة ({{rate}}%)» يُشتقّ من نفس الثابت (كان يشحن ٨٪ ويكتب ١٦٪).

### ٢) الولاء المرئي
- `Header.tsx`: شارة نقاط (كوب + الرصيد) مربوطة بمخزن الولاء، مع بوّابة `mounted` لتفادي عدم تطابق hydration.
- `MenuItemCard.tsx`: شارة «اكسب N نقطة» = `round(price × POINTS_PER_JOD)` على السعر قبل الضريبة.
- `home/LoyaltySection.tsx`: الكوب/التقدّم من المخزن الحقيقي.

### ٣) الوصولية
- `globals.css`: حدّ `:focus-visible` عام + حارس `prefers-reduced-motion`.
- أحجام/إضافات الصنف: أزرار `aria-pressed` داخل `role="group"` (بدل role=radio بلا نمط لوحة مفاتيح).
- أشرطة التقدّم (الكوب المجاني، مستوى المكافآت): `role="progressbar"` + `aria-valuenow/min/max`.
- شرائح الأصناف: `aria-current`. الأيقونات الزخرفية: `aria-hidden`.
- `lib/contrast.ts`: `readableTextOn` يختار الأعلى تباينًا بين الأبيض والبنفسجي الداكن لشارة المستوى.

### ٤) الأرقام اللاتينية
- `packages/shared/src/lib/format.ts`: تواريخ بـ`ar-JO-u-nu-latn` (اسم شهر عربي + رقم لاتيني).
- كل رقم ديناميكي معروض عبر `formatNumber(n, lang)`.
- تصحيح الأرقام الهندية الثابتة في `messages/ar.json`.

### ٥) حالات التحميل
- `components/ui/Skeleton.tsx` جديد؛ استُخدم بدل بوّابات الظهور الفارغة في السلة/المكافآت/المحفظة والمنيو.
- تنويه أعلى المنيو: «الأسعار لا تشمل ضريبة المبيعات ٨٪».

### ٦) تسريع القرار
- شارة «الأكثر طلبًا» للأصناف الشائعة.
- رفّ «شوهد مؤخرًا» عبر `store/recentStore.ts` (يُحلّ من بيانات overlay المطبَّقة، لا الخام — سعر/توفّر لا يتقادم).
- رقائق «الأكثر بحثًا» تحت شريط البحث.

### ٧) تنظيف
- `ComboBanner`: إيموجي ← أيقونات lucide.
- مكوّن الكمية: `aria-label` للأزرار.
- `hreflang` بين العربي/الإنجليزي في التخطيط.

## مراجعة لجنة الخبراء (٥ عدسات، تحقّق عدائي)
٩ ملاحظات مؤكّدة = ٤ مشاكل فريدة + nit، صُلِّحت كلها في `d61c993`:
1. **(major)** لابل ضريبة التطبيق الثابت «١٦٪» بينما يشحن ٨٪ ← اشتُقّ من الثابت.
2. `aria-label` نقاط الهيدر بلا بوّابة `mounted` ← عدم تطابق hydration، أُصلح.
3. «شوهد مؤخرًا» كان يتجاوز overlay الأدمن ← يُحلّ من `merged`.
4. `role=radio` بلا نمط لوحة مفاتيح ← أزرار `aria-pressed`.
5. **(nit)** `readableTextOn` كان يرجّع الداكن بلا مقارنة ← يختار الأعلى تباينًا.

ملاحظتان رُفضتا بحق بعد التحقّق (سلامة `format.ts`، وازدواج نداء الكوب موجود مسبقًا).

## التحقّق
- `npm run web:typecheck` → نظيف (0 أخطاء).
- `npm run lint --workspace almond-app` (tsc) → نظيف.
- `npm run web:build` → ينجح لكل الصفحات (عربي `/` + إنجليزي `/en`).
- لقطات: الرئيسية/المنيو/المكافآت (عربي RTL) + موبايل + إنجليزي — كل التعديلات ظاهرة.
